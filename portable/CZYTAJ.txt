S7Trace - wersja przenosna (nie wymaga Pythona ani internetu)

URUCHOMIENIE
  S7Trace.bat          - uruchamia program
  S7Trace-debug.bat    - to samo z oknem konsoli (gdy program sie nie uruchamia - pokaze blad)
  Symulator.bat        - lokalny symulator PLC; w programie wpisz IP 127.0.0.1:1102, rack 0, slot 2
  Diagnoza.bat         - sprawdza Windows, biblioteki Qt i kompletnosc plikow (wynik: diagnoza.txt)
  Web-Serwer.bat       - serwer trybu Web (HTTPS, port 8080): polaczenia ze sterownikami na tym komputerze,
                         uzytkownicy loguja sie przegladarka (https://<adres-serwera>:8080). Opcjonalnie:
                         Web-Serwer.bat plik_konfiguracji.json. Pierwsze konto (administrator) tworzy sie
                         w przegladarce. Przegladarka ostrzeze o certyfikacie samopodpisanym (to normalne).
                         Port 8080 trzeba odblokowac w zaporze Windows. Jest tez logowanie
                         kontem Windows (SSO, opcja --sso). Opis: app\WEB.md
  Test-TimescaleDB.bat - test zapisu/odczytu do TimescaleDB / PostgreSQL (psycopg i pg8000);
                         pyta o adres serwera, wynik: diagnoza_timescale.txt (wyslij go deweloperowi);
                         przy serwerze z rozszerzeniem timescaledb sprawdza tez kompresje i usuwanie
  Test-InfluxDB.bat    - test zapisu, odczytu i usuwania w InfluxDB 1.x / 2.x; pyta o wersje, adres i
                         dane logowania, wynik: diagnoza_influx.txt (wyslij go deweloperowi)

INSTALACJA NA INNYM KOMPUTERZE
  Skopiuj / rozpakuj CALY folder S7Trace (np. do C:\Dev\S7Trace - trzymaj sciezke krotka).
  Nie trzeba niczego instalowac.

GDZIE SA DANE
  Konfiguracja (zakladki, sygnaly, trigger):  %APPDATA%\S7Trace\config.json
  Zapisy triggera (snapshots), REC:           podfolder snapshots\ obok S7Trace.bat

AKTUALIZACJA
  Podmien tylko folder app\ (python\ zostaje bez zmian).

STEROWNIK
  S7-300/400: rack 0, slot 2.  S7-1200/1500: rack 0, slot 1,
  w CPU wlaczony 'Permit access with PUT/GET', DB bez 'Optimized block access'.
