Tokeny programów okienkowych

    
Program okienkowy (Ustawienia → Serwer Web) zgłasza serwerowi swoją sesję z takim tokenem; w zamian ostrzega przed
      skanowaniem sterownika, który skanuje ktoś inny. Token pokazuje się tylko raz – skopiuj go od razu.
